# Library Demo Run Guide

## Prerequisites
- JDK 17 or later (both `java -version` and `javac -version` must work)
- Python 3.9 or later
- Git

## Run the demo
From the repository root, run:

python3 run.py demo

On Windows, use `py -3 run.py demo` if that is how you run Python 3.

## What the demo does
It compiles the Java code into a temporary directory and runs a small demonstration of the library application: borrowing limits, loan periods, overdue fees, catalog search and loan receipts.
